# Short & Long

Short & Long — это сайт для работы с криптовалютным рынком. Он показывает данные бирж, помогает следить за монетами и проверять торговые идеи на исторических данных.

## Что можно делать

- Смотреть рыночные данные и информацию о монетах.
- Настраивать сканеры рынка и получать оповещения.
- Проверять торговые стратегии на прошлых данных.
- Просматривать историю движения цены и моделировать сделки.
- Читать собранные новости.
- Подключать аккаунт биржи для просмотра своей торговой статистики.

## Из чего состоит проект

- `frontend/web` — сайт, который открывается в браузере.
- `backend/api` — сервер, который обрабатывает запросы сайта и хранит данные.
- `backend/scanners` и `backend/workers` — сбор данных рынка, сканеры и оповещения.
- `backend/backtest` — проверка торговых стратегий на исторических данных.
- `backend/news` и `backend/telegram` — сбор новостей и отправка сообщений в Telegram.
- `docs` — инструкции, описания и примеры экранов.

## Как запустить

Для запуска нужны **Docker Desktop** и **PowerShell**. Откройте PowerShell в папке проекта и выполните:

```powershell
.\backend\production.ps1 start
```

Чтобы собрать и запустить сервисы заново:

```powershell
.\backend\production.ps1 build
```

## Запуск только сайта

Установите Node.js, затем выполните:

```powershell
cd frontend/web
npm install
npm run dev
```

Сайт работает вместе с серверной частью проекта. Для настройки локального запуска используйте примеры файлов `.env.example`; личные ключи и пароли в эти файлы добавлять нельзя.
