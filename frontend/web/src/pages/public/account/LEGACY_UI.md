# Резервная версия страницы аккаунта

Файл `AccountPage.legacy.tsx.disabled` — полная копия прежней реализации страницы аккаунта со всеми четырьмя вкладками на момент редизайна.

Он намеренно имеет расширение `.disabled`, поэтому Vite и TypeScript его не импортируют и не включают в пользовательскую сборку.

Для восстановления:

1. Сохранить текущий `AccountPage.tsx` под новым именем.
2. Скопировать содержимое `AccountPage.legacy.tsx.disabled` в `AccountPage.tsx`.
3. Выполнить `npm run lint` и `npm run build` из `frontend/web`.

API и структура данных в резервной копии соответствуют состоянию проекта на момент создания копии.
