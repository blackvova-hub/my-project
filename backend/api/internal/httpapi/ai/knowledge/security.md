2FA настраивается в `/account` → «Настройки аккаунта».

Чтобы включить 2FA, сначала нужно подтвердить email. Затем нажать «Включить 2FA»: сайт отправит шестизначный код на email, который нужно ввести в форме подтверждения. При входе в аккаунт с включённой 2FA код также приходит на email; на странице входа его можно запросить повторно.

Для выключения 2FA интерфейс запрашивает текущий пароль. Никогда не проси пользователя прислать пароль или код в чат.

Ниже в кабинете отображаются сеансы входа: устройство, браузер, операционная система, IP, дата и состояние сессии. Если пользователь не узнаёт сеанс, безопасный совет — завершить работу с аккаунтом, сменить пароль и проверить 2FA; помощник не может сам закрыть сеанс.
