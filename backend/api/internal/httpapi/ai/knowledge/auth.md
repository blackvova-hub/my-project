Страницы доступа:
- `/login` — вход по email и паролю. При включённой 2FA после первого шага нужно ввести код из email; код можно отправить повторно.
- `/register` — создание аккаунта.
- `/forgot-password` — запрос письма для восстановления пароля.
- `/reset-password` — установка нового пароля по ссылке из письма.

Если ссылка восстановления недействительна или истекла, нужно вернуться на `/forgot-password` и запросить новую. Не проси прислать пароль, ссылку восстановления или коды подтверждения в чат.

После входа пользователь попадает в интерфейс платформы. Управление профилем, 2FA, Telegram и сеансами находится в `/account`.
