# Аналитика трейдера

Новый кабинет: http://192.168.0.124/account. Демонстрация: http://192.168.0.124/account?demo=1. Вход использует существующие аккаунты сайта.

В разделе «Подключения» можно добавить ключ Bybit или Binance с доступом только для чтения. Сервер проверяет разрешения, шифрует ключи AES-256-GCM и запускает импорт. Торговых запросов коннекторы не отправляют. Установлен постоянный серверный `ANALYTICS_ENCRYPTION_KEY`: его нужно сохранять вместе с резервной копией базы и `.env`; менять при каждом деплое нельзя.

## Реализованные разделы

| Раздел | Работающие сценарии |
|---|---|
| Обзор | Пять показателей, стоимость/внесённый капитал/BTC, разбор движения денег, распределение активов, переход категория → символ → сделки → исполнения |
| Результаты | Шесть периодов, капитал/прибыль/доходность/просадка, 16 показателей, календарь, разбивки по символу/направлению/бирже/дню |
| Сделки | Фильтры биржи/символа/направления/результата/плеча/длительности/даты/тега/стратегии, сортировка, страницы, CSV, свечи и исполнения, редактирование пометок |
| Эффективность | Группировки по восьми измерениям, сравнение лонгов и шортов, кликабельная сетка день × час |
| Расходы | Комиссии, уплаченное и полученное финансирование, расходы по символу и бирже, мейкер/тейкер, расходы на доллар прибыли до расходов |
| Риски | Текущие позиции, валовой и чистый объём позиций, эффективное плечо, маржа, концентрация, текущая и максимальная наблюдаемая просадка |
| Закономерности | Десять типов детерминированных правил, размер выборки, уровень доказательности, формула и соответствующие сделки; отдельное ИИ-пояснение серверных агрегатов |
| Подключения | Подключение, проверка прав, очередь синхронизации, статусы/ошибки/покрытие, сверка снимков, отключение |

## Границы данных

- Текущие коннекторы восстанавливают **USDT linear** сделки Bybit Unified и **USDT USD-M futures** Binance. Это не полный импорт всех продуктов биржи: spot, options и coin-margined сделки не восстанавливаются. Bybit Unified wallet и журнал импортируются отдельно.
- Первый импорт Bybit запрашивает до двух лет (с однодневным запасом на границе доступности), Binance — 90 дней; далее обновление каждые 15 минут с перекрытием последнего дня и дедупликацией. Для существующего Bybit-подключения кнопка «История за 2 года» запускает повторный импорт без удаления ключей, пометок или ранее полученных событий. По умолчанию выбран период «Всё время». Ограничения истории и региона биржи сохраняются.
- История equity начинается с первого снимка. Для изменения equity, доходности и сверки нужны минимум два снимка. Предыдущие балансы и отсутствующие данные не моделируются. График BTC сравнивает исходную сумму с пассивным вложением, без добавления последующих пополнений в benchmark.
- USD, USDT и USDC используются по номинальному паритету. Историческая USD-переоценка другого залога не реализована; остаточная разница в сверке показана явно. Переводы между выбранными счетами суммируются со знаком, а не считаются доходом. Без истории за границами счёта нельзя надёжно отличить внешний депозит от перевода из другого продукта биржи.
- MFE/MAE считаются по минутным mark-свечам при открытии карточки сделки и сохраняются для закрытой позиции. Минуты с исполнениями исключаются из экстремумов: порядок событий внутри OHLC неизвестен. Это выборочная оценка, не tick-by-tick максимум. Ограничение графика — 30 000 минут.
- Историческое плечо, SL/TP и ликвидация показываются только при наличии данных; актуальные уровни открытой позиции не выдаются за исторические. Отдельная стоимость slippage не начисляется повторно: цена исполнения уже содержит её влияние. Исторический quote для оценки slippage пока не собирается.
- Незавершённая история открытия, неоднозначный funding hedge-позиций и комиссии без USD-оценки исключают сделку из статистики. Такой PnL не публикуется как достоверное число.
- Confidence — категория по объёму выборки, не статистическая вероятность. AI использует уже рассчитанные сервером агрегаты, не получает API-ключи; максимум 20 новых объяснений на пользователя в сутки, кеш по данным, детерминированный ответ при недоступности провайдера.
- Крупные импорты ограничены временем задачи (10 минут), 1000 страницами каждого запроса и 200 000 событиями интерактивного набора. Превышение даёт явную ошибку, а не молча обрезанную статистику.

Живой импорт Bybit проверен 27 сентября 2026 по местному времени: 194 исполнения, 624 записи журнала, 52 восстановленные сделки (все закрытые), история с мая 2025 по апрель 2026. Первоначальная пустота была вызвана ограничением импорта 90 днями; также исправлен пропуск принудительных закрытий. Проверен свечной график реальной закрытой сделки. Позднее владелец самостоятельно отключил Bybit, поэтому на текущем аккаунте подключения и импортированной истории нет; после нового подключения доступная история загрузится заново. Binance пока проверен на фикстурах. Живой ответ AI-провайдера не использовался как доказательство готовности импорта.

## Код и проверки

Frontend: `frontend/web/src/pages/analytics/`. Backend: `backend/api/internal/httpapi/analytics/`. Миграция: `069_trader_analytics.sql`.

```powershell
cd frontend/web
npm run build
npm run test:analytics
npx eslint src/pages/analytics src/app/App.tsx
# LIVE_ADMIN_PASSWORD задаётся через окружение, не через файл теста:
npm run test:analytics:live
```

Backend: `go test ./internal/httpapi/analytics ./cmd/api`. Интеграционный тест при наличии `ANALYTICS_TEST_DATABASE_URL` создаёт отдельную схему и удаляет её после проверки; действующие аккаунты не изменяет.

Только прежняя страница профиля заменена новым кабинетом `/account`. Остальные маршруты восстановлены вместе с исходными проверками авторизации и подписок. Исходный роутер для сравнения — `frontend/web/src/app/App.pre-analytics.tsx.disabled`. Общая шапка Header переиспользована в кабинете, остальные страницы сохранены.

Резервная копия до установки: `/opt/shortlong/backups/analytics-20260926-131815/`. `source-before.tar.gz` содержит заменённые исходники, `backend.env` — предыдущую конфигурацию, отдельная копия nginx — конфигурацию прокси. Возврат исходников не требует удаления таблиц аналитики; ключ шифрования новой установки следует сохранить.

См. [актуальный контракт и проверку русской версии](localization.md), [исходный визуальный контракт](design.md) и [первоначальный отчёт](verification.md).
