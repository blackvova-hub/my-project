# Проверка поиска похожих ситуаций

## Визуальная спецификация

Пользователь отклонил первоначальный концепт с таблицей и явно потребовал копировать существующий сайт: **шесть маленьких графиков, три в ряд и два ряда, в самом низу окна информации о монете**. Этот запрос заменяет первоначальный концепт. Новая палитра и оформление не вводились.

Источник стиля: `CoinResearchPanel.tsx`, `PerpChart.tsx`, существующие окна информации. Снимок исходного окна — [existing-coin-reference.png](existing-coin-reference.png). Реализация — [charts-desktop.png](charts-desktop.png), [charts-mobile.png](charts-mobile.png). Исходный макет таблицы не использован.

| Проверка | Источник | Реализация / исправление |
|---|---|---|
| Расположение | Уточнение пользователя: самый низ окна | SimilarityPanel после статистики во всех четырёх местах открытия |
| Компоновка | 6 графиков, 3 × 2 | Реальные 6 результатов, координаты проверены в Playwright |
| Палитра графика | PerpChart | Фон #0d1711, свечи #34d399/#fb7185, тени #6ee7b7/#fda4af |
| Сетка и шкалы | PerpChart | Та же библиотека, пунктирная сетка, цвета шкал и crosshair |
| Панели и подписи | CoinResearchPanel | Существующие border-white/10, bg-black/45, rounded-2xl, размеры подписей |
| Кнопки | PerpChart | Спокойный emerald border/background из существующего компонента |
| Мобильный экран | Существующее прокручиваемое окно | Один столбец на 390 × 844, проверено отсутствие горизонтального переполнения |
| Данные | Настоящие свечи и поиск | Реальный API, реальные OHLCV, нет фиктивных графиков |

Browser/IAB в сессии недоступен, использован Playwright с установленным Edge. Проверены 1536 × 1024 и 390 × 844. Через `view_image` непосредственно сопоставлены исходное окно и снимки реализации: цвета, типографика, рамки, плотность, геометрия графиков и мобильное размещение. Исходный график при снимке ещё загружал Bybit, поэтому цвета свечей также сверены непосредственно с кодом PerpChart.

Проверка текста: сохранены пользовательское название «Похожие ситуации» и привычные обозначения рынка. Новых заголовков над основным контентом/навигации нет. Добавлены необходимые подписи фильтров, времени, сходства, последующих исходов и честные состояния загрузки. Намеренное отличие от отклонённого макета — графики вместо таблицы, согласно прямому указанию пользователя.

## Функциональные проверки

- Сборки Go worker/API и frontend TypeScript/Vite прошли; контейнеры пересозданы из собранных образов.
- `go test ./...` и `go vet ./...` similarity прошли, включая интеграционный прогон с отдельными PostgreSQL, Redis, ClickHouse и Qdrant.
- Проверены независимость от масштаба цены/объёма, включая очень малые значения, нулевой опорный объём, разрывы, временные границы и отсутствие влияния future на signature.
- Проверены дедупликация, фильтры, курсоры, истечение lease, запрет завершения чужим token, обнаружение новой/старой истории без сброса прогресса.
- 40 одинаковых конкурентных запросов выполнили один общий ANN search.
- API-тесты проверяют авторизацию, cross-site запреты и ограничение размера тела; существующие backtest API тесты прошли.
- ESLint новых React-компонентов прошёл.
- `tests/similarity-live.mjs`: настоящий вход, реальный поиск BTCUSDT, 500 кандидатов, 6 результатов, автоматическая загрузка при прокрутке, шесть canvas-графиков, раскрытие breakdown, переключение same_asset, мобильный экран. Подмены API нет.

Полный векторный индекс продолжает наполняться в фоне. Последующие исходы созревают и индексируются независимо; прочерк не означает нулевую доходность. Производительность индекса на сотнях миллионов окон не проверена. Справочник секторов пока содержит начальную ручную классификацию, а не полный каталог всех активов.

Финальный прогон 14 сентября 2026: `ohlcv_v2_bc7bceba505a`, реальный API вернул 6 результатов из 500 кандидатов. После пересоздания проверено совпадение ID запущенного Docker-образа и собранного образа. Все 21 рабочий сервис запущены; тестовые PostgreSQL/Redis/ClickHouse/Qdrant остановлены. Последние снимки повторно просмотрены через `view_image`; соответствие уточнению пользователя и стилю существующего окна подтверждено по перечисленным пунктам, существенных визуальных расхождений не обнаружено.

Неиспользуемый `concept.png` с отклонённой таблицей остался только в документации: автоматическая проверка инструментов заблокировала команду удаления. Приложение его не загружает.
