# Таймфреймы и независимое управление графиками — 16.09.2026

- Общий переключатель 5м / 15м / 1ч / 4ч, по умолчанию 1ч; выбор сохраняется.
- Свечи загружаются из ClickHouse для шести результатов одним запросом, включая ранее сохранённые поиски. Переключение выполняется в браузере без повторного поиска и сетевых обращений.
- Каждая карточка независимо поддерживает перетаскивание, масштабирование колесом, горизонтальный жест на телефоне и сброс масштаба. Вертикальный жест остаётся прокруткой окна. Сброс вмещает весь доступный период даже на узком экране.
- Агрегация OHLC учитывает границы UTC, пропуски и границу сравнения; свечи на краях могут быть неполными. Индекс, ранжирование и окно поиска не изменены.
