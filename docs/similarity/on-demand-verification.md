# Поиск похожих ситуаций по запросу — 14 сентября 2026

Изменение собрано и запущено в существующем dev: backend, frontend, similarity_worker; конфигурация Qdrant применена. Новых постоянных сервисов нет. Временные изолированные сервисы интеграционных тестов остановлены после проверки.

## Что изменилось

- Открытие информации о монете и прокрутка к похожим ситуациям загружают только каталог параметров. Вычисления создаёт кнопка «Найти похожие».
- POST поиска возвращает 202 и ID задачи. В PostgreSQL сохраняются параметры, владелец, состояние, прогресс и результат. Есть отмена, восстановление после перезапуска и защита от доступа другого пользователя.
- Подготовка ограничена запрошенными рынком, размером окна и областью поиска. По умолчанию выбрана история этой монеты. Область «Все монеты» остаётся доступна, но первый такой поиск требует обработки выбранного окна по всему рынку.
- Подготовленные по новым запросам сигнатуры повторно используются. Автоматического расширения индекса и проходов по незапрошенным окнам нет. Доходности после совпадений считаются непосредственно из свечей только для найденных результатов.
- Прогресс активной задачи читается раз в 5 секунд. После завершения и отмены опрос прекращается. В скрытой вкладке периодический опрос отключён. Закрытие окна не отменяет запущенную задачу; для этого есть кнопка отмены.
- Без задач исполнитель ждёт уведомления. Резервная проверка очереди раз в 30 секунд восстанавливает задачи после сбоев и не читает историю свечей. Qdrant ограничен 2 CPU, исполнитель — 1 CPU. После записей Qdrant может завершать внутреннюю оптимизацию подготовленных данных.

## Очистка

По явному запросу пользователя удалены все 14 старых коллекций similarity_ohlcv (версии v1/v2), таблица предрассчитанных исходов similarity_outcomes_v1, курсоры/ремонты и кеш поиска. При первом проходе соединение с Qdrant оборвалось после двух удалений; повторный идемпотентный запуск завершил очистку остальных коллекций. Исходные свечи не затрагивались: 51 793 750 строк до и после первого полного прохода.

После реальных проверок удалены также созданные ими коллекции, задачи и курсоры. Финальное число строк свечей: 51 793 774 до и после очистки. 24 дополнительные свежие свечи BTC появились при проверке текущего окна поиска. Метаданные монет и история бэктестов сохранены.

Команда очистки отдельная, явно вызываемая оператором: `similarity -purge-derived`. При старте сервиса и при поиске не выполняется. Правила и команды описаны в [README сервиса](../../backend/similarity/README.md).

## Проверки

- Go unit и интеграционные тесты на отдельных PostgreSQL, Redis, ClickHouse и Qdrant прошли. Проверены реальные сигнатуры и ранжирование, исходы без доступа к будущему относительно запроса, 40 одинаковых конкурентных обращений с одним поиском, ограничение выбранной монетой/окном, отсутствие фоновых задач, права владельца, отмена, лимит активных задач, token/lease и восстановление после остановки.
- `go vet ./...` модуля similarity прошёл. Тесты API проверили авторизацию, защиту POST/DELETE от cross-site, ограничение тела запроса, передачу полного пути задачи и замену поддельного заголовка владельца на ID из проверенной сессии.
- TypeScript и ESLint изменённого React-компонента прошли; production-сборки frontend, backend и similarity_worker завершились успешно.
- В Edge через Playwright: открытие/прокрутка — 0 POST поиска; нажатие — 202, подготовка BTC/Futures/1h, 6 настоящих графиков с исходами; повторное использование, раскрытие оценок, сетка 3 × 2, мобильная версия без переполнения, прекращение опроса после завершения, отмена поиска по всем монетам, восстановление отменённого состояния после перезагрузки без повторного запуска. Ошибок JavaScript страницы нет.
- Проверочный поиск и его сохранённые данные удалены после QA. Финальный контроль простоя проверяет пустые коллекции, нулевые задачи/курсоры/ремонты, отсутствие таблицы исходов при сохранённой таблице свечей и отсутствие записей в Qdrant за 35 секунд.
