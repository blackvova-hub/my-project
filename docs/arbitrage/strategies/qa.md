# Проверка визуального соответствия

Применены frontend-app-builder и React best practices. Концепт `concept.png` подготовлен и просмотрен до frontend-изменений; пользователь затем уточнил, что нужен фильтр доступности, а не объём ордера. Это уточнение имеет приоритет. Реальные данные сохранены, растровый концепт не используется как фальшивая рабочая таблица.

Browser/IAB проверен: подключённых поверхностей нет. Использован Playwright в Edge с обычной авторизацией реального сайта. Снимки desktop сделаны в исходном размере концепта **1536×1024**, mobile — **390×844**. Концепт и свежие снимки обычного режима, LP и mobile просмотрены через `view_image` в одном QA-проходе; отдельно проверены Light/Dark/Green. Геометрия тем измерена в браузере и совпала.

| --- | --- | --- |

| Содержание таблицы | Монета / Купить / Продать / разница / объём / длительность | Обычные колонки сохранены; «Доступно, USDT» — числовое значение из backend. Метрика и последний столбец меняются по стратегии; реальные цены и quantities вместо нарисованных |
| Композиция | Две панели: controls и таблица, раскрытый dropdown | Одна существующая панель сайта, как заранее записано в spec. Dropdown закрыт по умолчанию, пауза в заголовке; поиск на строке режимов. Таблица остаётся центральной частью страницы |

| Палитра и поверхности | Холодная светлая серо-зелёная поверхность, зелёный акцент | Использованы существующие background/card/border/primary tokens. Light/Dark/Green меняют цвета, не размеры. Не добавлены градиенты, свечение или декоративные растровые assets |

| Адаптивность | Детальный mobile не нарисован | Controls вертикально, биржи 3×2, горизонтальная прокрутка только таблицы. Все пять новых режимов проверены на 390 px, документ не выходит за viewport. Дополнительные LP-поля сдвигают результаты ниже по странице — намеренное следствие необходимых параметров |

В ходе сверки исправлены: отсутствие рамки нового dropdown, длинное обрезанное название выбора сетей и некорректная подпись условия CEX↔CEX. Для общего выбора сети используется «Обе сети», отдельные варианты — Ethereum и Arbitrum. В деталях XEMM maker buy показывает текущие bid, maker sell — ask, с оговоркой об очереди.

Сохранены «Арбитраж», «Связки», «Все», «Избранное», названия шести бирж, прежние три режима, поиск, основные колонки и навигация текущего сайта. `Сумма, USDT` → `Мин. доступно, USDT`; `Объём` → `Доступно, USDT`; `Разница на сумму` → `Разница цен` — изменения по уточнению пользователя. Добавлены названия пяти стратегий и пояснения их условий, необходимые в заказанном workflow. Для LP/Redemption заголовок ограничивает охват до «Пулы ETH / BTC» и «USDC / USDe», вместо ложного «Все монеты». Горизонт/сеть/диапазон/расчётная позиция — функциональные параметры заказанных стратегий, не рекламные вставки.

Сохраняются существующие Header, «Админка» для текущей роли, переключатель SL и AI-помощник. Они отличаются от нарисованной шапки концепта намеренно, по требованию пользователя использовать текущий сайт. Не добавлялись CTA торговли, marketing headings, decorative badges или вторые системы стиля.

Существенных неустранённых визуальных дефектов после этих исправлений не обнаружено. Реализация сверена с концептом по текстам, композиции, типографике, палитре, контролам, иконкам, интервалам и mobile с перечисленными намеренными отличиями. Это проверка соответствия согласованному направлению и существующему сайту, без заявления об идентичности концепту пиксель в пиксель.
