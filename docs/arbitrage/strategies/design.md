# Стратегии и глубина: спецификация

Уточнение пользователя после концепта: главный числовой control заменён на «Мин. доступно, USDT». Колонка остаётся «Доступно, USDT», вместо `filled/requested`. В обычном арбитраже это фильтр известных сопоставимых положительных уровней, без размера ордера. Для Funding/XEMM/Redemption/LP дополнительно показывается отдельная «Расчётная позиция, USDT», необходимая для денежных оценок и delta; она не подменяет фильтр.

Концепт: [concept.png](concept.png), 1536×1024, просмотрен до изменения frontend. Используем существующий Header, AnimatedSelect, SegmentedControl, Lucide и semantic tokens. Одна панель с выбором стратегии, суммой USDT, поиском, режимами и биржами; одна таблица. 16 px панель, 12 px controls, текст 14/12, H1 36/30. Light/Dark/Green имеют одинаковую геометрию. Мобильный вид: controls вертикально, биржи 3×2, таблица с горизонтальной прокруткой.

Разрешённые названия стратегий: Обычный арбитраж; Мгновенный CEX↔CEX; Funding Arbitrage; XEMM; Redemption / Depeg; Hedged LP. Сумма, USDT; Найти монету; прежние 3 режима; прежние 6 бирж. Для funding добавляется горизонт, для LP диапазон и сеть: необходимы для расчёта. Колонки адаптируются: funding за горизонт, лимитная цена/хедж XEMM, номинал/дисконт redemption, APY пула/размер short LP. Нет кнопок реальной торговли.

Намеренные отличия от изображения: существующая шапка имеет приоритет; сохраняется одна панель; биржа над ценой, как раньше; dropdown закрыт по умолчанию; пауза в заголовке; реальные данные вместо нарисованных; «Недостаточно глубины» относится к объёму, а не длительности. Для условных стратегий видны конкретные ограничения: доступ к погашению, исполнение maker-заявки, исторический APY и перебалансировка LP. Никаких вымышленных процентов готовности/прибыли.

Backend переиспользует книги, каталоги, quantity steps, VWAP, funding-адаптеры, авторизацию, preferences и favorites. Дополнительная глубина загружается по общим запросам в Redis с ограничением частоты, без отдельного транспорта для каждого браузера. LP: публичные данные DefiLlama, проверенные токены, цена из Uniswap v3 pool на фиксированном блоке; USD-якорь из Kraken. Redemption — кандидаты USDC/USDe с условиями, а не обещание автоматического погашения.
