# Доверие локальному HTTPS

- [x] **Добавить локальный HTTPS CA сервера в доверенные сертификаты Windows текущего пользователя.** Выполнено 14.10.2026 после явного разрешения пользователя. Отпечаток повторно сверён через SSH. Обычный Windows HTTPS-клиент получил 200; Edge без `ignoreHTTPSErrors` вошёл в настоящую LiveKit-комнату. Микрофон не включался.
- [ ] **Android пользователя:** установить тот же CA вручную и проверить связь с ноутбуком. Два устройства должны войти под разными аккаунтами в одну криптопару.

Сертификат доступен по [HTTP-ссылке сервера](http://192.168.0.130/voice-local-ca.crt). SHA-256 отпечаток DER-сертификата:

```text
487A2D2368EB6015A5C0935227A70A6154F2A98A19EB2CB34F9AA9D13E43D6E1
```

На других устройствах сертификат автоматически не установлен. Перед установкой сверить отпечаток; доверие выдаётся именно этому локальному CA. Для Android: скачать CRT, в настройках безопасности выбрать установку **сертификата CA**, затем открыть HTTPS-страницу в Chrome. Названия пунктов зависят от производителя. Для теста звука разрешить микрофон браузеру и включить его в комнате.

Страница: [Голосовой чат](https://192.168.0.130/community/voice). Инструкция и ограничения LAN находятся в [README](README.md).
