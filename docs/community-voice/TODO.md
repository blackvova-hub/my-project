# Отложено пользователем

- [ ] **Добавить локальный HTTPS CA сервера в доверенные сертификаты Windows текущего пользователя.** Пользователь 14.10.2026 попросил сделать это позже. Сертификат на ПК не устанавливался; серверный голосовой чат и HTTPS уже работают.

Сертификат доступен по [HTTP-ссылке сервера](http://192.168.0.130/voice-local-ca.crt). SHA-256 отпечаток DER-сертификата:

```text
487A2D2368EB6015A5C0935227A70A6154F2A98A19EB2CB34F9AA9D13E43D6E1
```

Перед будущей установкой повторно сверить отпечаток с CA сервера, затем импортировать сертификат в `CurrentUser\Root` с разрешения пользователя. После установки проверить HTTPS обычным клиентом без отключения проверки TLS и разрешить микрофон браузеру.

Страница: [Голосовой чат](https://192.168.0.130/community/voice). Инструкция и ограничения LAN находятся в [README](README.md).
