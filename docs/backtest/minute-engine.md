# Минутный расчёт стратегий

С 16.10.2026 новые тесты используют реальные закрытые минутные свечи. Выбор 1h/4h и блок «Срабатывания условий входа» удалены. Лимиты пар: Free — 6, Standard — 10, Pro — 15; API проверяет тариф авторизованного пользователя.

Рост цены за окно — наибольшее движение от более раннего минимума к последующему максимуму. Последовательность 100 → 150 → 120 содержит рост 50%; обратная последовательность не становится ростом. Для снижения порядок зеркальный. Внутри одной минуты порядок high/low не предполагается: учитываются только гарантированные open→high и low→close, для снижения — open→low и high→close. Вход происходит на открытии следующей минуты после закрытого сигнала.

У каждой пары своё доступное начало и прогрев. Старые пары сохраняют полный запрошенный период; новый листинг не обрезает остальные инструменты. Внутренние и конечные пропуски после доступного начала остаются ошибкой. Старые результаты сохраняют исходные настройки, а новые запуски из черновика или импорта переходят на 1m.

OI, CVD, delta и объёмы рыночных покупок/продаж сохраняют нативную часовую частоту. На минутной шкале их условия доступны только при закрытии часа. Промежуточные наблюдения не выдумываются, часовые объёмы не распределяются по минутам.

Поиск последовательных экстремумов и волатильность используют очередь агрегатов за O(N), а не повторный перебор окна. Чтение свечей ClickHouse потоковое, без прежнего ограничения ответа 64 MiB.
