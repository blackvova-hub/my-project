# Оформление тестера в стиле сайта — проверка 10.09.2026

Обновление собрано и запущено на http://localhost:3000/backtest. Проверялся настоящий nginx frontend после пересоздания Docker-контейнера, вход через локальный тестовый аккаунт и работающий API. Все 18 сервисов локального стека запущены; frontend, API, PostgreSQL, Redis и ClickHouse healthy.

## Визуальное основание и метод

Главный эталон — существующий сайт, согласно прямому требованию пользователя: [сканер 1536×1024](site-reference.png), пользовательские скриншоты и исходные стили ScannerConfig/PublicLayout. Вспомогательные концепты Image Gen: [конструктор](concept-builder.png), [результаты](concept-results.png). Токены и решения зафиксированы до реализации в [design.md](design.md).

Browser/IAB в доступных инструментах отсутствует. Использован Playwright с настоящим Microsoft Edge, headless, deviceScaleFactor 1. Скриншоты сняты через `page.screenshot`; оба концепта, эталон сайта и последние реализации открыты через `view_image`. Основное сравнение выполнено на нативном размере 1536×1024; результаты дополнительно просмотрены на нативных 390×1024. Полный мобильный снимок использовался только для проверки порядка разделов, без оценки мелкого текста по уменьшенному изображению.

Последняя реализация: [форма](rendered-builder.png), [результаты](rendered-results.png), [результаты на телефоне](rendered-results-mobile.png).

## Тексты и намеренные отличия

Тексты шапки, название страницы, подзаголовок, история и поля сохранены. Добавлены функциональные пресеты «30 дней», «90 дней», «1 год», подсказка «0 — без тейк-профита» и title для периода индикатора. Убраны номера 01/02/03, которых нет в сканере. Других новых рекламных надписей и декоративных бейджей не добавлено.

Концепт конструктора получился шире и темнее исходного сайта: реализация сознательно следует размерам и палитре сканера, как просил пользователь. Подчёркивание навигации из концепта не добавлялось в существующую шапку. Внутреннее оформление условий взято из сканера. Подписи несколько контрастнее исходного gray-500.

В результатах сохранены настоящие данные, интерактивный lightweight-charts с его атрибуцией, 20 сделок на страницу, существующая пагинация назад/вперёд и отдельная раскрывающаяся методика. Иллюстративные числа, четыре строки таблицы, заливка под графиком и нумерованные страницы из концепта не заменяют работающие компоненты. Существующие понятные названия TP/SL сохранены. AI-виджет остаётся скрытым на странице инструмента.
