# Графики — общая система Short & Long

Новая авторизованная страница `/charts` добавлена в обычную и мобильную навигацию. Она использует существующие React, TypeScript, Lightweight Charts 5.2, technicalindicators и темы Light / Dark / Green. Новых runtime-зависимостей нет.

## Возможности

- Bybit / Binance, спот и USDT-фьючерсы; реальные REST-свечи и WebSocket, восстановление соединения, обновление истории и подгрузка при прокрутке влево. Таймфреймы 1м, 5м, 15м, 30м, 1ч, 4ч, 1д, 1н. Точность цены берётся из tick size конкретного инструмента.
- Свечи, бары, линия, область; масштабирование мышью и касанием, перемещение, автошкала, логарифмическая шкала, полноэкранный режим и PNG с разметкой.
- Раскладки 1 / 2 / 4 графика, выбор активного окна, поиск по реальному каталогу биржи, общий список избранного и сравнение доходности от первой общей свечи.
- Все 22 существующих индикатора, включая Smart Money; отдельные изменяемые по высоте панели. Настройка периодов и до восьми дополнительных экземпляров классических индикаторов. По умолчанию EMA 50, EMA 200 и RSI 14. MACD использует 12/26/9, Ichimoku — 9/26/52, VWAP — сессию UTC.
- Публичные деривативные панели: OI в базовом активе, фактические ставки funding, базис mark/index и отношение long/short аккаунтов. Данные обновляются раз в минуту. API Bybit и Binance имеют разные ограничения глубины; недоступные значения не становятся нулём.
- 76 инструментов разметки: линии, лучи, каналы, регрессия, Фибо, вилы, Ганн, фигуры, настоящая трёхточечная дуга, кривые Безье, кисть/маркер, текст и экранные заметки, гармонические паттерны и волны Эллиотта, циклы, Long/Short, диапазоны, проекции, шаблоны баров и профиль объёма по свечам.
- Выделение, перемещение целого объекта и опорных точек, редактирование координат/текста/цвета/толщины/штриха/заливки, копирование, ластик, блокировка, скрытие, список объектов, магнит к OHLC и повторное рисование. Undo/redo хранит последние 50 операций, включая редактирование.
- Автосохранение разметки в браузере отдельно по пользователю и инструменту; явное сохранение объектов, таймфрейма и основного списка индикаторов в существующем `/api/chart/config`. Именованные рабочие пространства и полный JSON импорт/экспорт сохраняются в браузере.

Горячие клавиши работают внутри активного графика: Escape, Delete/Backspace, Ctrl/Cmd+Z, Ctrl/Cmd+Shift+Z, Ctrl/Cmd+Y, Ctrl/Cmd+S; Alt+T/H/J/V/C/F — соответствующие инструменты. Enter завершает ломаную. Поля ввода сохраняют обычное поведение клавиатуры; диалоги удерживают фокус и закрываются Escape.

## Архитектура

Единственный вызов `createChart` находится в `frontend/web/src/shared/charts/engine.ts`. Свечные графики используют `ChartSurface`; финансовые временные ряды — `TimeSeriesChart`. Компактные и категориальные представления используют `Sparkline`, `MarketSummaryCharts` и `StatCharts` в той же общей папке.

`marketData` и `useMarketData` владеют транспортом; `derivatives` — публичными дополнительными рядами; `useChartWorkspace` — совместимым сохранением. `drawings/model` задаёт каталог и нормализацию; `geometry` вычисляет геометрию; `DrawingEditor` обрабатывает взаимодействие; `useDrawingHistory` хранит операции.

График не пересоздаётся при движении курсора, новой свече или переключении темы. Индикаторы обновляют существующие серии; отложенные вычисления отменяются при смене данных. Разметка использует публичные API координат, requestAnimationFrame и мемоизированный редактор. Pane resize не сбрасывается на каждом тике. Данные проверяются, сортируются и дедуплицируются; отсутствующие балансы и разрывы арбитражной истории отображаются отдельными сегментами.

## Полный перечень перенесённых представлений

| Прежнее место | Новое представление / сохранённый контракт |
|---|---|
| `shared/market/PerpChart` | Адаптер `MarketChart`; сохранены сканеры, избранное, новости рынка и виджеты сигналов, нормализация символов и старые настройки |
| `shared/market/SimilarityChart` | `ChartSurface`; сохранены агрегация выбранного таймфрейма и отметка границы найденного окна |
| `pages/public/replay/ReplayChart` | `ChartSurface`; передаются только видимые свечи, сохраняются выбор начала, виртуальная позиция, controls и возврат масштаба |
| `pages/public/backtest/EquityChart` | `TimeSeriesChart`; исходный серверный капитал и временные метки |
| `pages/analytics/Charts` | Общие временные ряды и свечи; финансовые формулы, исполнения, вход/SL/TP/ликвидация сохранены |
| `pages/public/arbitrage/RouteDetails` | Общий временной ряд с разрывом при паузе наблюдений более 90 секунд; таблица исходных точек сохранена |
| `MarketInsightsWidget` | Общие sparkline, распределение и gauge; прежние источники и расчёты |
| `analytics/Overview`, `Performance`, `Analysis` | Общие stacked/metric bars и heatmap; прежние фильтры и переходы к сделкам |

Старые `replay/Drawings`, `replay/useDrawings` и неиспользуемый `ChartToolIcon` удалены. `perpMarketData` оставлен совместимым адаптером общего транспорта. Проверены также `.disabled` копии роутера/кабинета: самостоятельного графического runtime в них нет; они не подключены к приложению.

Сессии replay по-прежнему очищают собственную разметку при новом архиве/старте. Их разметка экспортируется вручную, но автоматически не переносится между сессиями: прежние состояния и образцы баров не должны подмешиваться в новый тренировочный проход. Модель виртуальных сделок, очередь бэктестов, расчёты аналитики и подписки не изменены.

## Границы реализации

- Это собственный терминал на открытой Lightweight Charts. Закрытые функции/данные CoinGlass и полный проприетарный TradingView не копируются: liquidation heatmap, агрегированный межбиржевой CVD/footprint, точный volume-at-price и закрытые индикаторы требуют соответствующего источника данных. Эти функции не изображены работающими кнопками.
- Профиль объёма распределяет фактический объём свечей по диапазону OHLC; это обозначенная оценка, не распределение исполнений по цене. Для регрессии/профиля/шаблона баров используются 2–500 выбранных загруженных свечей.
- Волны и паттерны размечаются вручную. Нет автоматического распознавания, Pine Script, брокерских ордеров или гарантий прогнозов. Long/Short рассчитывает риск, прибыль и R/R по пользовательским уровням и количеству.
- Угол, окружность и квадрат Ганна зависят от экранного масштаба; координаты ценовых объектов привязаны к рынку. Шаблон баров / обычная проекция переносят абсолютные изменения, проекция цены — относительные.
- История графика ограничена 15 000 свечами, разметка — 100 объектами на набор и 800 точками кисти. Серверное сохранение сохраняет прежние ограничения 50 наборов / 256 KiB; при превышении данные остаются в браузере и доступен JSON. Раскладки, параметры дополнительных экземпляров и именованные пространства пока не синхронизируются между браузерами.
- OI/L/S на 1м имеют исходный шаг 5м. На больших таймфреймах показано последнее наблюдение внутри интервала; funding не суммируется. Недельные наблюдения привязаны к понедельнику UTC. Глубина деривативных API ограничена провайдерами.
- WebSocket и REST зависят от доступа браузера к бирже, CORS, региональных ограничений и лимитов провайдера. Ошибки/неполнота показаны в интерфейсе; синтетические котировки не подставляются.

## Запуск и проверка

```powershell
cd frontend/web
npm run build
npm run lint
npm run test:charts
node --experimental-strip-types --test tests/*.test.mjs
npm run test:charts:live
```

Live-проверка по умолчанию обращается к `http://127.0.0.1:5173/charts`. Она использует настоящий рыночный API. Для локальной проверки доступен существующий DEV-only route guard; для обычного подключённого сайта можно задать `CHARTS_E2E_URL` и `CHARTS_E2E_STORAGE` тестового аккаунта. Production-сборка сохраняет авторизацию. Запуск всего стека — прежний `backend/production.ps1 build`; обновлённый backend нужен для серверного сохранения новых типов объектов.

Актуальное подтверждение: [verification.md](verification.md), [browser-verification.json](browser-verification.json).

Развёрнутая страница в LAN: <http://192.168.0.130/charts>. Production-проверка с обычным входом и сохранением в PostgreSQL: [server-2026-10-12/browser-verification.json](server-2026-10-12/browser-verification.json), 25 успешных сценариев. Compose и исходные данные сервера сохранены; обновлены только frontend/backend.

Официальные источники контрактов: [Lightweight Charts primitives](https://tradingview.github.io/lightweight-charts/docs/plugins/series-primitives), [Bybit OI](https://bybit-exchange.github.io/docs/v5/market/open-interest), [Bybit long/short](https://bybit-exchange.github.io/docs/v5/market/long-short-ratio), [Binance market data](https://developers.binance.com/en/docs/catalog/core-trading-derivatives-trading-usd-s-m-futures/api/rest-api/market-data), [CoinGlass endpoints](https://docs.coinglass.com/reference/endpoint-overview).
