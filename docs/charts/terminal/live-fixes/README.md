# Обновление свечей и исправление шкалы объёма

13 октября 2026. Проверки и развёртывание выполняются на сервере `192.168.0.130`, без локального запуска приложения.

Предыдущая схема использовала WebSocket и резервный запрос полной истории каждые 30 секунд. [Bybit описывает частоту kline 1–60 секунд](https://bybit-exchange.github.io/docs/v5/websocket/public/kline), поэтому одного этого потока недостаточно для секундной проверки текущей свечи.

Теперь общий feed инструмента/интервала проверяет две последние реальные свечи раз в секунду, если WebSocket не присылал свежих данных. Быстрый WebSocket продолжает работать сразу. Одинаковые окна используют один feed; запросы не накладываются, отменяются после ухода последнего подписчика и приостанавливаются в скрытой вкладке. Устаревший REST-ответ не заменяет более новый WS-бар. Догрузка пропущенной истории отделена от обновления текущей свечи. При сетевой ошибке или ограничении биржи применяется backoff; изменение самой цены каждую секунду не гарантируется и не имитируется.

Исправлена граница единиц при восстановлении логарифмических price ranges в Lightweight Charts 5.2.1: `getVisibleRange` возвращает реальные величины, а setter использует пространство логарифмов. Ряд объёма раньше мог экспоненциально раздувать шкалу. Восстановление теперь проверяет обратное преобразование и выполняется после готовности новой панели. Сохранённые повреждённые диапазоны объёма сбрасываются в Auto по фактическим данным. Формат шкалы ограничивает длину больших чисел, включая T и научную запись. Исходные биржевые объёмы не обрезаются и не заменяются нулями.

Проверки: TypeScript, ESLint, 92 frontend unit tests, production build; отдельный серверный Chromium-сценарий с реальным Binance REST при намеренно отключённом WebSocket, испорченным сохранённым диапазоном и ручной логарифмической шкалой после перезагрузки. Точные измерения и результат: [verification.json](verification.json). В этом сценарии настройки аккаунта только читаются; тестовые предпочтения находятся в отдельном браузерном контексте.

Регрессии сохранения, рисунков, тем и раскладок проверяются существующим `terminal-live.mjs`. Скриншот шкалы: [volume-log-restored.png](volume-log-restored.png).
