# Проверка системы графиков

12 октября 2026, рабочая станция, локальный frontend preview.

## Дизайн

Концепт: `docs/charts/concept.png`, встроенный Image Gen. Brief: полная страница «Графики» Short&Long в существующей зелёной теме, оригинальная шапка, плотная панель инструментов, основной свечной график, индикаторные панели, левый редактор, правая watchlist и обзор; без новых градиентов, glow, glass и маркетингового hero. Визуальное направление совпадает с существующим сайтом.

Проверка браузером: встроенный IAB недоступен (`Browser is not available: iab`); использован Playwright / Microsoft Edge. Концепт и конечные скриншоты просмотрены через `view_image`, при размере 1536×1024 и мобильном 390×844.

Сверены пять основных областей: исходная шапка и темы; компактные controls/типографика; левый rail и разметка; нативные свечи/сетка/оси и отдельные панели; правая watchlist и обзор. Фирменная палитра, разделители и сдержанные формы сохранены. Проверены Light / Dark / Green; схема и размеры не меняются между темами.

Осознанные отличия от концепта: настоящие цены и история вместо концептуальных чисел; исходная гостевая шапка в локальной DEV-проверке, обычная авторизованная навигация — в коде; объём расположен перед RSI. Дополнительные деривативные панели включаются пользователем. Реализация визуально сверена с концептом и архитектурой существующего проекта; точное пиксельное совпадение с растровым концептом не заявляется.

## Исправленные проблемы

- Удаление уже уничтоженных нативных серий при смене типа/размонтировании: добавлен lifecycle guard и владелец runtime.
- Черновик трёхточечного Фибо мог обращаться к ещё не созданной точке: неполная геометрия рисуется безопасно.
- Первоначальный resize overlay не учитывал добавленные панели: отслеживаются также размеры нативной панели.
- Многографиковое сохранение могло перезаписывать соседний набор: перед записью объединяется актуальный storage.
- Индикаторы пересоздавали панели на каждом обновлении: обновляются сохранённые серии, размеры не сбрасываются на каждом тике.
- Разрывы наблюдений/пустые балансы теперь разделены на самостоятельные серии, без соединения отсутствующих данных.
- Старые сохранённые ключи `exchange:symbol:interval` читаются совместимо; новая разметка разделяет также spot/linear.
- Недельные деривативные ряды выровнены по понедельнику UTC.

## Проверка после развёртывания на server01

12 октября 2026 обновлены frontend и backend на `server01`. Рабочая страница: <http://192.168.0.130/charts>, доступна в локальной сети. После перезагрузки сервер получил адрес `192.168.0.130` вместо `192.168.0.124`; прежний frontend не запускался из-за привязки порта к отсутствующему адресу. SSH-ключ сервера проверен по ранее сохранённому ключу. Исправлены привязка порта и backend CORS/FRONTEND_URL; адрес задаётся через `SERVER_LAN_IP` в серверном `.env`.

Перед обновлением сохранены исходники, конфигурация и прежние Docker-образы. Серверный отчёт и лог сборки: `/opt/shortlong/reports/charts-deploy-20261012T104324Z`. Compose пересобрал и пересоздал только `backend` и `frontend`; оба контейнера имеют статус healthy. `/charts`, `/health`, `/api/health` вернули HTTP 200; `/api/auth/me` без cookie вернул ожидаемый HTTP 401.

Playwright / Microsoft Edge проверил опубликованную production-сборку через обычную форму входа администратора LAN. Все **25 сценариев** прошли, runtime errors: **0**. Проверены реальные Bybit/Binance, четыре деривативных ряда, индикаторы, редактирование разметки, undo/redo, повторная загрузка, все темы, Фибоначчи и Long Position, PNG/JSON, таймфрейм, четыре типа отображения, 2/4 графика, сравнение и мобильный экран. Дополнительно проверены серверное сохранение новых объектов и чтение их обратно через API из PostgreSQL; исходная конфигурация аккаунта восстановлена после проверки. Ордеры и внешние уведомления не отправлялись.

Доказательства: [server-2026-10-12/browser-verification.json](server-2026-10-12/browser-verification.json), скриншоты трёх тем и мобильной версии в той же папке. Пароли, cookie и секреты в отчёт не включены.
